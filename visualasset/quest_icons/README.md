# 儿童成长冒险 RPG — 五种任务类型图标

复古 16-bit 像素 RPG UI 风格的任务图标组，一套统一视觉系统，共 5 枚独立图标。

## 交付文件

| 文件 | 尺寸 | 说明 |
| --- | --- | --- |
| `quest_icons/quest_icons_1x5.png` | 1664×384 | 五枚图标 1×5 横向排列总图，透明背景 |
| `quest_icons/01_daily.png` … `05_bounty.png` | 256×256 | 单枚图标，透明背景，可直接使用 |
| `quest_icons/native32/*.png` | 32×32 | 原生像素尺寸，供引擎 / 精灵图集使用 |
| `quest_icons/preview_light_dark.png` | 1664×776 | 深底 + 浅底自检预览（验证透明背景） |
| `build_icons.py` | — | 生成脚本（可改色 / 改形后一键重出） |
| `verify_icons.py` | — | 交付自检脚本 |

## 图标对照

| # | 任务类型 | 核心视觉 | 含义 |
| --- | --- | --- | --- |
| 1 | 日常任务 | 打开的书本 + 小星星 | 每天要完成的学习与日常 |
| 2 | 冒险任务 | 背包 + 地图卷轴 + 指南针 | 长期成长、旅程与目标 |
| 3 | 世界任务 | 卷轴 + 小型世界地图 + 地图标记 | 阶段性重要目标与世界事件 |
| 4 | 风物任务 | 小花 + 叶片 + 草丛 | 户外活动、生活体验、观察自然 |
| 5 | 悬赏任务 | 悬赏卷轴 + 金色星标 | 临时发布、限时完成的特别任务 |

## 规格

- **原生栅格**：32×32，统一 1px 深藏青描边（描边引擎自动外扩，五枚绝对一致）
- **放大倍率**：×8 整数倍 NEAREST，无插值、无抗锯齿、无半透明像素
- **布局**：单格 256px，格间距 64px，外留白 64px —— 间距区域完全透明，可直接按格裁切
- **光源**：统一左上受光、右下压暗，最多 3 色调
- **用色**：全套仅 25 色
- **背景**：完全透明（无投影、无装饰背景）
- **禁止元素**：无人物、无文字、无数字、无 UI、无按钮、无完整场景
