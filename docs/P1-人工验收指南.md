## 0. 一次性准备（每轮验收开始时执行一次）

### 0.1 确认环境（浏览器）

1. 浏览器打开 `http://localhost:8500` —— 应看到"话话成长系统"登录页（**Web 正常**）。
2. 浏览器打开 `http://localhost:8500/api/health` —— 应看到 `{"status":"ok",...,"db":"up"}`（**Nginx→API→数据库 正常**）。
3. 命令行确认容器：`docker compose ps` —— postgres 应为 healthy，api/web 为 Up。

### 0.2 定义便捷命令（整块复制到 PowerShell）

```powershell
$BASE = "http://localhost:8500/api"        # Docker 环境入口
$T    = "$env:TEMP"
# 写 JSON body 文件（避免引号问题）
function J($name, $json) { Set-Content "$T\$name.json" $json -NoNewline -Encoding Ascii; return $name }
# 调用 API：打印返回体 + [HTTP 状态码]
function Call($method, $path, $token, $bodyName) {
  $h = @("Content-Type: application/json")
  if ($token) { $h += "Authorization: Bearer $token" }
  if ($bodyName) { curl.exe -s -w "`n[HTTP %{http_code}]" -X $method "$BASE$path" -H $h[0] -H $h[1] -d "@$T\$bodyName.json" }
  else { curl.exe -s -w "`n[HTTP %{http_code}]" -X $method "$BASE$path" -H $h[0] -H $h[1] }
}
# 查数据库
function Q($sql) { docker exec huahua-postgres psql -U huahua -d huahua -t -c $sql }
```

> 说明：POST 成功默认返回 `201`（NestJS 语义，等同 2xx 成功）；下面"预期状态码"按实际输出为准。

### 0.3 重置数据（每轮验收前执行，保证结果可预期）

```powershell
Q "DELETE FROM approval_records; DELETE FROM reward_grants; DELETE FROM task_completions; DELETE FROM approval_requests; DELETE FROM tasks; DELETE FROM user_growth; DELETE FROM refresh_tokens; DELETE FROM users;"
```
执行后确认：`Q "SELECT COUNT(*) FROM users;"` 应输出 `0`。

### 0.4 创建测试用户 + 设置家庭 + 登录拿 Token

```powershell
# 注册家长与孩子
J p  '{"username":"parent1","password":"secret123","role":"parent"}'
Call POST "/auth/register" $null "p"          # 预期 201：{"user":{"username":"parent1","role":"parent",...}}
J c  '{"username":"child1","password":"secret123","role":"child"}'
Call POST "/auth/register" $null "c"          # 预期 201
# 设置 familyId（当前无家庭 API，P1 用 SQL 直接赋值；P2 会补正式入口）
Q "UPDATE users SET family_id=(SELECT id FROM users WHERE username='parent1') WHERE username IN ('parent1','child1');"
Q "SELECT username, family_id FROM users;"
# 登录并保存 Token 到文件
J lp '{"username":"parent1","password":"secret123"}'
J lc '{"username":"child1","password":"secret123"}'
$pt = (curl.exe -s -X POST "$BASE/auth/login" -H "Content-Type: application/json" -d "@$T\lp.json" | ConvertFrom-Json).accessToken
$ct = (curl.exe -s -X POST "$BASE/auth/login" -H "Content-Type: application/json" -d "@$T\lc.json" | ConvertFrom-Json).accessToken
Set-Content "$T\ptok.txt" $pt -NoNewline
Set-Content "$T\ctok.txt" $ct -NoNewline
Write-Output "tokens saved (parent/child): $($pt.Length) / $($ct.Length)"
```
> Token 有效期 30 分钟；超时后重跑 0.4 的登录两行即可。

后续所有场景先读 Token：

```powershell
$pt = Get-Content "$T\ptok.txt" -Raw
$ct = Get-Content "$T\ctok.txt" -Raw
$cid = (Q "SELECT id FROM users WHERE username='child1';").Trim()
$pid = (Q "SELECT id FROM users WHERE username='parent1';").Trim()
```

## E. reviewer reject → returned

```powershell
J tc ("{`"childId`":`"$cid`",`"title`":`"阅读打卡C`",`"requiresApproval`":true,`"reviewerId`":`"$pid`"}")
```

## G. 非 reviewer 不能审批

```powershell
# 注册第二个家长（非指定审核人），并登录

# 新任务指定审核人=parent1；parent2 去审批 → 403
J td ("{`"childId`":`"$cid`",`"title`":`"任务G`",`"requiresApproval`":true,`"reviewerId`":`"$pid`"}")
```
